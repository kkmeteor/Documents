# PET-CT 质控与参数管理全流程

## 一、校准数据与计算逻辑

### 1. 质控数据融合与 Pas 原始信号

统筹 Pas 采集的 int mode 原始信号数据
前置处理经 PDC 校验的结果数据

### 2. 快速计算策略与 S / 阈值门槛

当所需数据满足了 40% 不计算
两天数据不累积，直接重算
下班前可计算一次，阈值为 2.5G

### 3. 质控结果分级与状态标识

- 绿色：所有单体均为正常
- 红色：辐射单体有个体超两个异常
- 黄色：其他单体异常的情况
- 灰色：重置 / 未计算 / 中断

### 4. 计算结果导出与文件

存储格式为 root data DCM 归档
包含总量、study ID 列表、时间及三色校验

### 5. 校验逻辑与异常记录

仅作全局展示，不修改硬件参数
逻辑变更长期留存自动更新

## 二、温度参数闭环控制

### 1. 水温状态阈值与不可达

1~2~21 为统一变化范围，不可逆向
21 表示温度维持可穿戴区域

### 2. 开环 / 闭环逻辑与参数表

- 水温为 21 时仅取第一套闭环参数
- 水温为 24/28 取第二套参数表
- 水温为 21 分为闭环第一套 / 开环为 1

### 3. 每分钟自动水温迭代

支持环境 / 主机温度变更适配
ULA / 冷链水温状态有了比对

### 4. 1~21 段温度固定采集 15 分钟

初始以持续约 5 分钟的稳定服务
周期内按主动温度以分钟为

### 5. 21~1 段按需用户手动确认

每次修改需要选择自行下的阈值
可追加以算子的入口 / 手动恢复
每次修改有变更项 / 修改记录的格式

## 三、图像格式管理

### 1. CT 数据解析为 raw 格式顺序

CT 仅存 datacon 压缩文件，需转换为 raw
转换后文件命名按 CT 序列 ID
手动拖拽 datacon 范围限制原生生效

### 2. 基于完整原生 DICOM 的特点

输入为 CT/PET 的像素值，体素大小等元信息
输出 DICOM 文件在 LA 中可被识别

### 3. 用户确认选择并应用参数

后处理模块同步参数文件 / 时间 / 扫描日期
历史结果可复用，支持跨科室应用

## 四、核素校正 & 生场体系

### 1. 百级核心数据线生成规范

提供核素关键量、NACR、图像量、分辨率
再校正 / 核心 PCF 全测数据、头阈值、判定项 / 可讨论
输入参数包含源名、环境、源 / 类型、文件关联等

### 2. 独立 web 程序实现图像采集

确保为独立环境 PCG 采集，禁止修改 / 数字验证
根据出分析需要实时刷新并一并入生成程序

### 3. 图像元素：校正系数、积分 / 峰值 / 线源 / 衰减

支持 nat、GKD、nova 等多机型 / 多套衰减

### 4. 支持离线手动 / 自动生成

校验量与外部组件文件一致，可手动替换
需手动输入多参数的独立工具 / 数据生成

## 五、系统安全与权限配置

### 1. 账号权限分级管理

- 管理员 / 不同级别可开放权限
- 普通用户仅可修改 / 交互密码
- Doctor 均默认无写 / 可管理权限

### 2. 数字证书 / 单一账号 / 多组权限

证书 / 组织 11 月至 12 月权限
更新 / 变更为打开申请→单字 / 交叉验证 / 加盖章
更新 / 变更需重新校验，其余时间 / 配置不变
