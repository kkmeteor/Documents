# 项目结构重组说明

## 📁 新的目录结构

MCP相关文件已移动到独立的 `mcp-server/` 目录中。

### 重组前
```
MD/
├── tfs_health_mcp.js          ← MCP服务文件（根目录）
├── package.json               ← 项目配置（根目录）
├── node_modules/              ← 依赖包（根目录）
└── .qoder/skills/...          ← Skill定义
```

### 重组后
```
MD/
├── mcp-server/                ← 新增：MCP服务专用目录
│   ├── tfs_health_mcp.js      ← MCP服务主文件
│   ├── package.json           ← Node.js项目配置
│   ├── package-lock.json      ← 依赖锁定文件
│   ├── node_modules/          ← 依赖包
│   ├── README.md              ← MCP服务说明文档
│   ├── MCP配置更新说明.md      ← 配置更新指南
│   └── verify-setup.js        ← 配置验证脚本
│
└── .qoder/skills/tfs-changeset-query/
    ├── SKILL.md               ← Skill主指令
    ├── examples.md            ← 使用示例
    └── README.md              ← Skill说明（已更新路径）
```
