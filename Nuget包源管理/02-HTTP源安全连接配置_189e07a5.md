# HTTP 私有源安全连接配置

## 一、背景

私有 NuGet 源使用 **HTTP 协议**（如 `http://10.10.11.194:1001/v3/index.json`）而非 HTTPS 时，NuGet 默认会拒绝该不安全连接，导致 `restore` 失败。

## 二、解决方案

必须在 `NuGet.Config` 文件中将 **`allowInsecureConnections`** 设置为 `true`，以允许不安全连接。

## 三、关键配置位置（易错点）

`allowInsecureConnections` 配置项**必须位于 `<config>` 节点下**，而**不是** `<packageSources>` 节点内。

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <!-- ★ allowInsecureConnections 必须在这里（<config> 节点下）★ -->
  <config>
    <add key="allowInsecureConnections" value="true" />
  </config>

  <packageSources>
    <clear />
    <add key="InternalNuGet" value="http://10.10.11.194:1001/v3/index.json" />
  </packageSources>
</configuration>
```

## 四、排查要点

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 配置 HTTP 源后 `restore` 失败 | `allowInsecureConnections` 未开启 | 在 `<config>` 节点下添加 `allowInsecureConnections=true` |
| 配置了该项但依然报错 | 该项误放在 `<packageSources>` 内 | 移至 `<config>` 节点下 |

> 该配置位置是实践中最容易出错的地方，多份来源文档均强调同一要点。
