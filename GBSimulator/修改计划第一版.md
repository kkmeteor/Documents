# GBSimulator 动态床位系统 - 项目总结

## 项目概述

本项目为 GBSimulator 添加了动态床位配置、规则引擎和预置数据管理功能，实现了根据参数动态加载床位信息和 listmode 数据的需求。

## 实现的功能

### Phase 1: 动态床位配置系统 ✅
- 支持 JSON 配置文件
- 支持任意数量的床位
- 配置管理器单例模式
- 向后兼容原有参数

### Phase 2: GBSimulatorViewModel 重构 ✅
- 适配器模式桥接新旧代码
- 动态床位 ViewModel
- 最小化对现有代码的改动
- 保持向后兼容性

### Phase 3: 规则引擎 ✅
- 灵活的规则接口
- 多种预定义规则（成人全身、心脏、脑部、儿童、模体）
- 规则优先级和置信度
- 根据患者类型和扫描类型自动匹配

### Phase 4: 预置数据管理器 ✅
- 预置数据信息管理
- 自动创建默认预置
- 根据规则自动匹配预置
- 数据完整性验证

### Phase 5: 动态 UI 生成 ✅
- 动态床位控制界面
- 规则选择对话框
- 预设选择功能
- 配置保存/加载界面

### Phase 6: 集成测试 ✅
- 完整的测试指南
- 快速测试脚本
- 15+ 个测试用例
- 常见问题排查

## 使用示例

### 基本用法

```bash
# 默认启动（6床位）
GBSimulator.exe

# 动态设置床位数量
GBSimulator.exe Beds=8

# 使用配置文件
GBSimulator.exe Config=myconfig.json
```

### 规则引擎

```bash
# 使用患者类型和扫描类型
GBSimulator.exe Patient=Adult Scan=WholeBody

# 使用规则名称
GBSimulator.exe Rule=AdultCardiac

# 使用预设场景
GBSimulator.exe Preset=adult_wholebody_standard
```

### 混合参数

```bash
GBSimulator.exe Patient=Adult Scan=WholeBody Beds=8 ExcpectedSpeed=150 AutoLaunch=true
```

### 向后兼容

```bash
# 原有参数仍然有效
GBSimulator.exe BedPositionFiles="bp1.lm,bp2.lm" AllSendSameFile=true ExcpectedSpeed=120
```

## 规则说明

| 规则名称 | 优先级 | 床位数量 | 适用场景 |
|---------|-------|---------|---------|
| Phantom | 3 | 1 | 模体/质控扫描 |
| AdultCardiac | 5 | 1 | 成人心脏扫描 |
| AdultBrain | 5 | 1 | 成人脑部扫描 |
| Pediatric | 8 | 4 | 儿童扫描 |
| AdultWholeBody | 10 | 6 | 成人全身扫描 |
| Default | 100 | 6 | 默认配置 |
